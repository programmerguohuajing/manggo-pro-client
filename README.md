# Manggo Pro Client (全功能桌面级翻译与听写工作台)

轻量、高性能、免侵入的桌面全功能翻译与语音工作台。

---

## 🌟 核心功能全景对照矩阵

| 功能模块 | 快捷键 / 触发方式 | 说明 |
| :--- | :--- | :--- |
| **输入框就地转译 (Pro 核心特性)** | 连按 **3 次空格** (`Space`) | 在微信/Word/聊天框打完中文连按 3 次空格，自动消除空格就地替换为英文。 |
| **划选文本悬浮翻译** | **Alt + Q** | 鼠标划选任意文本后按下，弹出沉浸式悬浮翻译卡片，支持朗读、复制、生词本收藏。 |
| **全屏截图 OCR 翻译** | **Alt + W** | 全屏十字光标框选，RapidOCR 本地离线识别文字并自动对照翻译。 |
| **桌面翻译工作台** | **Alt + M** / 托盘菜单 | 沉浸式双栏长文本中英互译工作台，支持多段翻译、一键朗读与复制。 |
| **语音听写输入 (Voice Input)** | **Alt + Space** | 唤起麦克风拾音指示气泡，实时转文字就地打字上屏。 |
| **历史记录 & 生词本** | 点击托盘 📖 按钮 / 工作台 | 本地 SQLite 自动存档。 |
| **离线语音朗读 (TTS)** | 🔊 按钮 (悬浮窗/工作台) | 调用 Windows 原生 SAPI 语音合成引擎，秒级离线发音，不消耗任何流量。 |
| **多翻译通道 (含 Pro 级大模型)** | 双击托盘 / 托盘右键 ⚙️ | 内置免 Key 极速通道，一键预设 DeepSeek-V3/R1、通义千问、OpenAI、本地 Ollama。 |
| **现代化偏好设置中心** | **双击右下角系统托盘图标** | 现代卡片式与侧边导航布局，支持连击灵敏度滑块、风格模板与一键测试。 |

---

## ⌨️ 快捷键速查表 (独立不冲突)

- **`连续 3 次空格`**：输入框就地转译（中文 -> 英文）
- **`Alt + Q`**：鼠标划选文本翻译（划选后一键呼出）
- **`Alt + W`**：全屏截图 OCR 文字识别与翻译
- **`Alt + M`**：呼出桌面主翻译工作台
- **`Alt + Space`**：语音听写输入
- **`双击右下角芒果托盘`**：呼出偏好设置中心
- **`Ctrl + Enter`**：在主翻译工作台中提交翻译

## 🚀 启动与使用

### 方式一：便携包（推荐，不用装 Python）

本地打包方法见 [`packaging/README.md`](packaging/README.md)（`pyinstaller manggo-pro-client.spec`），或在仓库 Actions 页下载对应平台的产物，解压即用：

- **Windows**：双击 `ManggoProClient.exe`（窗口程序，无黑框）
- **macOS**：打开 `ManggoProClient.app`，未签名，首次请右键 → 打开，放行一次
- **Linux**：直接运行 `ManggoProClient` 文件

### 方式二：源码运行（需要 Python 3.12）

```bash
pip install -r requirements.txt
```

- **日常使用（后台静默运行，无黑框）**：`pythonw main.py`
- **调试排查（带控制台日志输出）**：`python main.py`
- 程序会自动提权（管理员权限）并保证单实例；退出点托盘右键 → 退出

### 日志与诊断

- 托盘菜单 → 诊断控制台：可按级别过滤、复制、清空日志（不自动弹窗）
- 程序目录旁的 `debug_app.log`：同样可直接打开查看
