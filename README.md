# Manggo Pro Client (全功能桌面级翻译与听写工作台)

轻量、高性能、免侵入的桌面全功能翻译与语音工作台，**100% 完整对齐并升级原版 Manggo 全套功能矩阵与原生快捷键体系**。

---

## 🌟 核心功能全景对照矩阵

| 功能模块 | 原版 Manggo 对应快捷键 | 新版增强特性说明 |
| :--- | :--- | :--- |
| **输入框就地转译 (Pro 核心特性)** | 连按 **3 次空格** (`Space`) | 在任意聊天框/文档/浏览器输入中文后连击 3 次空格，自动消除空格并将文字直接替换为地道英文 |
| **划选文本悬浮翻译** | **Alt + D** / **Alt + Q** | 鼠标划选任意屏幕文本后呼出沉浸式卡片，支持朗读、复制、折叠、生词本收藏 |
| **全屏截图 OCR 翻译** | **Alt + X** / **Alt + W** | 全屏十字光标框选，RapidOCR 本地离线识别文字，中英对照翻译 |
| **语音听写输入 (Voice Input)** | **Alt + Space** | 唤起麦克风拾音指示气泡，实时转文字就地打字上屏 (Win+H / 语音输入联动) |
| **桌面翻译工作台** | **Alt + Shift + D** / 托盘菜单 | 沉浸式双栏长文本中英互译工作台，支持多段翻译、一键朗读与复制 |
| **历史记录 & 生词本** | 点击托盘 📖 按钮 / 工作台 | 本地 SQLite 自动存档，**已自动一键同步原版 Manggo 全部历史记录数据** |
| **离线语音朗读 (TTS)** | 🔊 按钮 (悬浮窗/工作台) | 调用 Windows 原生 SAPI 语音合成引擎，秒级离线发音，不消耗任何网络流量 |
| **多翻译通道 (含 Pro 级大模型)** | 双击托盘 / 托盘右键 ⚙️ | 内置免 Key 极速通道，一键预设 DeepSeek、通义千问、OpenAI、本地 Ollama |
| **现代化偏好设置中心** | **双击右下角系统托盘图标** | 现代卡片式与侧边导航布局，支持连击灵敏度滑块、风格模板与一键测试 |

---

## ⌨️ 快捷键速查表 (全兼容原版 Manggo)

- `连续 3 次空格`：输入框就地转译（中文 -> 英文）
- `Alt + D` 或 `Alt + Q`：划选文本翻译
- `Alt + X` 或 `Alt + W`：全屏截图 OCR 识别与翻译
- `Alt + Space`：语音听写输入
- `Alt + Shift + D`：呼出桌面翻译工作台
- `双击系统托盘图标`：打开现代化偏好设置中心
- `Ctrl + Enter`：在主翻译工作台中提交翻译

## 📂 项目结构

```text
manggo-pro-client/
├── core/
│   ├── hook.py            # Windows 底层低级键盘钩子 (全套兼容热键)
│   ├── replacer.py        # 消除空格、Extended Key 导航与就地替换引擎
│   ├── translator.py      # 内置国内极速通道与大模型 Pro 级通道
│   ├── ocr.py             # RapidOCR 离线文字识别引擎
│   ├── tts.py             # 原生 SAPI 语音朗读引擎
│   └── database.py        # SQLite 本地存储 (支持原版历史数据自动无损同步)
├── ui/
│   ├── float_window.py    # 划词悬浮翻译卡片
│   ├── snipping.py        # 全屏截图与选区框选遮罩
│   ├── voice_window.py    # 语音输入与听写指示气泡
│   ├── main_window.py     # 沉浸式桌面主翻译工作台
│   ├── history_window.py  # 历史记录与生词本管理面板
│   ├── settings_window.py # 现代化偏好设置中心 (侧栏导航+卡片流)
│   ├── toast.py           # 悬浮状态通知气泡
│   └── tray.py            # 系统托盘与右键菜单
├── main.py                # 主程序协调入口 (单实例互斥)
├── 启动助手(调试控制台).bat
└── 后台静默启动.vbs
```
