# Manggo Pro Client (全功能桌面翻译工作台)

一套轻量、纯本地、对标原版 Manggo 全功能及 Pro 权益的独立客户端。

---

## 🌟 全功能矩阵

| 功能模块 | 快捷键 / 触发方式 | 说明 |
| :--- | :--- | :--- |
| **输入框就地转译 (Pro 特性)** | 连按 **3 次空格** (`Space`) | 在微信/Word/聊天框打完中文后连按 3 次空格，自动消除空格并将文字就地替换为英文 |
| **划词悬浮翻译** | **Alt + Q** | 鼠标划选任意文本后按下快捷键，光标旁弹出悬浮卡片，支持中英互译、朗读与一键复制 |
| **截图 OCR 翻译** | **Alt + W** | 全屏十字光标拖拽框选，本地毫秒级提取文字并自动完成翻译对照 |
| **软件设置面板** | **双击系统托盘** / 托盘右键 | 配置翻译通道 (内置免Key / DeepSeek / 通义千问 / OpenAI)、连击灵敏度等 |
| **主翻译工作台** | **Alt + D** / 托盘右键 | 沉浸式双栏对照翻译面板，支持中英互译、长文本翻译、一键朗读与复制 |
| **离线语音朗读 (TTS)** | 悬浮窗或主窗口 🔊 按钮 | 调用 Windows 原生 SAPI 语音合成引擎，秒级离线发音，不消耗任何流量 |
| **历史记录 & 生词本** | 点击托盘或主窗口 📖 按钮 | 基于本地 SQLite 数据库自动存档，支持检索、生词星标收藏、一键导出与清理 |

---

## ⌨️ 默认快捷键一览

- `连续 3 次空格`：输入框就地转译（中文 -> 英文）
- `Alt + Q`：划选文本翻译
- `Alt + W`：全屏截图 OCR 翻译（Esc 或鼠标右键可随时取消）
- `Alt + D`：呼出/激活主翻译工作台
- `Ctrl + Enter`：在主工作台中直接触发翻译

## 📂 项目结构

```text
│   ├── hook.py            # Windows 底层低级键盘钩子 (3次空格, Alt+Q, Alt+W, Alt+D)

│   ├── float_window.py    # 划词与 OCR 悬浮结果卡片
│   ├── main_window.py     # 桌面主翻译双栏工作台
│   ├── history_window.py  # 历史记录与生词本管理面板

│   ├── toast.py           # 悬浮状态通知气泡
│   └── tray.py            # 系统托盘与右键菜单
├── main.py                # 主程序协调入口
├── 启动助手(调试控制台).bat
└── 后台静默启动.vbs
```
