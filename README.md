# Manggo Pro Client (输入框就地转译助手)

轻量、高性能、免侵入的桌面输入框快捷转译助手，完整支持 Manggo Pro 套餐下的核心特性——**在任意输入框连续敲击 3 次空格键，自动将当前输入的中文就地转译为流畅英文**。

---

## ✨ 核心亮点

1. **三击空格就地转译 (Triple-Space In-place Translation)**：
   - 在任意应用程序（如微信、企业微信、Slack、浏览器、Notepad、Word、VS Code 等输入框中），打完中文后**快速按 3 次空格键**；
   - 助手会自动清除敲击的 3 个空格，智能捕捉光标前文本或选中文字；
   - 毫秒级转换为地道英文并自动粘贴替换，保留光标连贯输入体验。
2. **免 Key 开箱即用 + Pro 级大模型支持**：
   - **默认内置免费高速通道**：无需注册任何 API Key 即可直接使用；
   - **大模型 Pro 通道**：全面兼容 OpenAI 格式 API（支持配置 **DeepSeek-V3 / DeepSeek-R1**、**阿里通义千问 Qwen**、**OpenAI**、**本地 Ollama** 等），可自定义 Prompt 获得极其地道、商务、学术级别的翻译表达。
3. **极简优雅反馈**：
   - 配备 Windows 任务栏上方轻量悬浮气泡（Toast），不抢夺焦点，提示“正在转译”与“完成结果”。
4. **系统托盘与常驻后台**：
   - 提供金黄色芒果托盘图标，支持随时一键暂停/恢复快捷键监听，或打开参数配置界面。

---

## 🚀 快速启动

- **调试运行（带命令行输出）**：
  双击运行目录下的 `启动助手(调试控制台).bat`
- **后台无感运行（推荐日常使用）**：
  双击运行目录下的 `后台静默启动.vbs`（后台静默托盘运行，没有任何黑框干扰）

---

## ⚙️ 目录结构

```text
manggo-pro-client/
├── core/
│   ├── hook.py            # Windows 底层低级键盘钩子 (WH_KEYBOARD_LL)
│   ├── replacer.py        # 消除空格、捕获光标文本、就地替换引擎
│   └── translator.py      # 免费通道与大模型 Pro 通道管理器
├── ui/
│   ├── toast.py           # 悬浮状态通知气泡
│   ├── settings_window.py # 设置与参数配置界面
│   └── tray.py            # 系统托盘与右键菜单
├── main.py                # 主程序协调入口
├── config.json            # 配置文件（自动生成）
├── 启动助手(调试控制台).bat
└── 后台静默启动.vbs
```

## 🛠️ 高级配置与自定义

右键右下角系统托盘小图标点击 **“转译设置”**：
- **连击时间窗口**：默认 550ms，可根据您的打字习惯调整连按空格的灵敏度；
- **大模型 Pro 引擎切换**：填入您的 API Base URL、API Key 与 Model 名称，即可无限制享用顶级大模型就地翻译。
