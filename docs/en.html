Desktop translation & dictation workbench

Lightweight, fast, non-intrusive: selection translation, screenshot OCR, voice dictation and in-place input-box translation, all from one tray icon.

Features

A complete translate–dictate–review workflow; recognition and history stay on your machine.

In-place input-box translation

Type Chinese in WeChat, Word or any chat box, press Space 3 times, and it is replaced in place with English.

Selection popup translation

Highlight any text and press Alt + Q for a popup card with read-aloud, copy and vocabulary-book save.

Screenshot OCR translation

Draw a box on screen; RapidOCR recognizes the text locally and offline, then translates it.

Desktop workbench

A two-column Chinese–English workbench for long text, with multi-paragraph translation, read-aloud and copy.

Voice dictation

Alt + Space starts system dictation (Win + H on Windows); what you say is typed in place.

History & vocabulary book

A local SQLite archive that is searchable and starrable.

Offline speech

Windows SAPI, macOS say, Linux espeak: all offline, no network traffic.

Multiple channels

A built-in key-free channel, plus one-click presets for DeepSeek, Qwen, OpenAI and local Ollama.

Preferences center

Custom hotkeys, triple-space sensitivity, translation style templates and a one-click connection test.

Download & install

Pick the build for your platform on the Releases page; the Windows installer comes with a setup wizard.

Windows

Installer ManggoProClient-Setup.exe, or portable ManggoProClient-Windows-x64.zip: unzip and double-click.

macOS

ManggoProClient-macOS-Intel.dmg / ManggoProClient-macOS-AppleSilicon.dmg. Not notarized by Apple; right-click → Open on first launch.

Linux

manggo-pro-client_<version>_amd64.deb or ManggoProClient-Linux-x64.tar.gz: unpack and run.

All releases →

Every Release ships a SHA256SUMS file; the in-app update check verifies downloads against it and refuses a mismatch.

Run from source (Python 3.12 required):

pip install -r requirements.txt
python main.py     # with console logs, for debugging
pythonw main.py    # Windows: silent background run, no console

Channels & privacy

What leaves your machine, in one place.

Built-in free channel

Sends selected and OCR text to Youdao's public endpoint, Google's web relay and MyMemory in turn; OCR itself still runs locally.

LLM channel

Only talks to the API address you enter. No fallback to the free channel by default (opt in under Settings); local Ollama needs no key.

Keys & logs

On Windows the API key is stored with DPAPI encryption, on macOS / Linux it is currently plain text; logs stay on your machine — check them before sharing.
