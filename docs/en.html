Features

A complete translate–dictate–review workflow that runs locally; history and vocabulary are archived automatically.

In-place input-box translation

Type Chinese in WeChat, Word, or chat boxes, press Space 3 times, and the text is replaced in place with English.

Selection popup translation

Highlight any text, press Alt + Q, and a popup card appears with read-aloud, copy, and vocabulary-book save.

Fullscreen screenshot OCR

Draw a crosshair box over the screen; RapidOCR recognizes text locally and offline, then translates it side by side.

Desktop translation workbench

Immersive two-column workbench for long Chinese-English texts, with multi-paragraph translation and one-click read-aloud.

Voice dictation input

Alt + Space brings up a microphone indicator; speech is transcribed and typed in place in real time.

History & vocabulary book

Local SQLite archive — review past translations and saved words anytime.

Offline speech synthesis

Uses the Windows native SAPI engine: instant offline pronunciation, no network usage.

Multiple translation channels

Built-in key-free fast channel, plus one-click presets for DeepSeek, Qwen, OpenAI, and local Ollama.

Modern preferences center

Card + sidebar navigation layout, triple-space sensitivity slider, style templates, one-click testing.

Download & install

Pick the package for your platform on the Releases page. The Windows installer includes a setup wizard.

Windows

Installer ManggoProClient-Setup.exe, or portable ManggoProClient-Windows-x64.zip — unzip and double-click.

macOS

ManggoProClient-macOS-Intel.dmg / ManggoProClient-macOS-AppleSilicon.dmg; unsigned — on first launch, right-click → Open to allow it once.

Linux

manggo-pro-client_*.deb or ManggoProClient-Linux-x64.tar.gz — extract and run directly.

Run from source (Python 3.12 required):

pip install -r requirements.txt
pythonw main.py   # silent background run, no console
python main.py    # debugging, with console log

The app auto-elevates and enforces a single instance; quit from tray right-click → Quit. Logs and diagnostics: tray menu → Diagnostics console, or debug_app.log next to the program.
