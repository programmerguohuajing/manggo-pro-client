功能一览

覆盖翻译、听写、查词的完整工作流，识别与存档都在本地完成。

输入框就地转译

微信、Word、聊天框里打完中文，连按 3 次空格，自动消除空格就地替换为英文。

划选文本悬浮翻译

划选任意文本，Alt + Q 呼出悬浮翻译卡片，支持朗读、复制、生词本收藏。

全屏截图 OCR 翻译

十字光标框选屏幕区域，RapidOCR 本地离线识别文字并自动对照翻译。

桌面翻译工作台

双栏长文本中英互译，支持多段翻译、一键朗读与复制。

语音听写输入

Alt + Space 唤起系统听写（Windows 调用 Win + H），说话即上屏。

历史记录与生词本

本地 SQLite 自动存档，可搜索、可星标，随时回顾。

离线语音朗读

Windows SAPI、macOS say、Linux espeak，全部离线发音，不耗流量。

多翻译通道

内置免 Key 通道，一键预设 DeepSeek、通义千问、OpenAI、本地 Ollama。

偏好设置中心

自定义热键、连击灵敏度、翻译风格模板，并可一键测试连接。

下载与安装

在 Releases 页选择对应平台的安装包；Windows 安装版自带安装向导，装完即用。

Windows

安装版 ManggoProClient-Setup.exe，或便携版 ManggoProClient-Windows-x64.zip，解压双击即用。

macOS

ManggoProClient-macOS-Intel.dmg / ManggoProClient-macOS-AppleSilicon.dmg。未经 Apple 公证，首次请右键 → 打开。

Linux

manggo-pro-client_<版本>_amd64.deb 或 ManggoProClient-Linux-x64.tar.gz，解压直接运行。

查看全部版本 →

每个 Release 都附带 SHA256SUMS；程序内「检查更新」下载后会自动校验，不一致即拒绝安装。

从源码运行（需要 Python 3.12）：

pip install -r requirements.txt
python main.py     # 带控制台日志，便于排查
pythonw main.py    # Windows：后台静默运行，无黑框

翻译通道与隐私

哪些数据会离开你的电脑，一次说清楚。

内置免费通道

会把选中文本与 OCR 文本依次发给有道公共接口、Google 网页翻译中继和 MyMemory；识别本身仍在本地离线完成。

大模型通道

只发给你填写的 API 地址。失败时默认不回退到免费通道，需要时可在设置里手动开启；本地 Ollama 无需 Key。

密钥与日志

Windows 上 API Key 以 DPAPI 加密保存，macOS / Linux 目前为明文；日志仅在本机，反馈问题前请先检查内容。
