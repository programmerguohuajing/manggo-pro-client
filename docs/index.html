功能一览

覆盖翻译、听写、查词的完整工作流，全部本地运行，历史与生词自动存档。

输入框就地转译

微信、Word、聊天框里打完中文，连按 3 次空格，自动消除空格就地替换为英文。

划选文本悬浮翻译

鼠标划选任意文本，Alt + Q 呼出悬浮翻译卡片，支持朗读、复制、生词本收藏。

全屏截图 OCR 翻译

全屏十字光标框选，RapidOCR 本地离线识别文字并自动对照翻译。

桌面翻译工作台

沉浸式双栏长文本中英互译，支持多段翻译、一键朗读与复制。

语音听写输入

Alt + Space 唤起麦克风拾音气泡，实时转文字就地打字上屏。

历史记录与生词本

本地 SQLite 自动存档，随时回顾翻译历史与收藏的生词。

离线语音朗读

调用 Windows 原生 SAPI 语音合成，秒级离线发音，不消耗任何流量。

多翻译通道

内置免 Key 极速通道，一键预设 DeepSeek、通义千问、OpenAI、本地 Ollama。

现代化偏好设置

卡片式 + 侧边导航布局，连击灵敏度滑块、风格模板、一键测试。

快捷键速查

各快捷键相互独立，不冲突。

下载与安装

在 Releases 页选择对应平台的包。Windows 安装版自带安装向导，装完即用。

Windows

安装版 ManggoProClient-Setup.exe，或便携版 ManggoProClient-Windows-x64.zip，解压双击即用。

macOS

ManggoProClient-macOS-Intel.dmg / ManggoProClient-macOS-AppleSilicon.dmg，未签名，首次请右键 → 打开放行一次。

Linux

manggo-pro-client_*.deb 或 ManggoProClient-Linux-x64.tar.gz，解压直接运行。

源码运行（需要 Python 3.12）：

pip install -r requirements.txt
pythonw main.py   # 后台静默运行，无黑框
python main.py    # 调试排查，带控制台日志

程序会自动提权并保证单实例；退出点托盘右键 → 退出。日志与诊断见托盘菜单 → 诊断控制台，或程序目录旁的 debug_app.log。
